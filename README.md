# Organizaê — Gerenciador de Tarefas Web

Aplicação web interativa para gerenciamento de tarefas diárias, desenvolvida com HTML5, CSS3 e JavaScript puro, sem o uso de frameworks externos.

🔗 **Acesse a aplicação online:** [\[https://nicole04a.github.io/organizae/\](https://nicole04a.github.io/organizae/)](https://nicole04a.github.io/organizae/)

## Funcionalidades Implementadas
- **Cadastro de tarefas:** Adição de tarefas com escolha de nível de prioridade (Baixa, Média ou Alta).
- **Listagem dinâmica:** Exibição organizada com identificação visual de prioridade e status.
- **Conclusão e Edição:** Marcação de tarefas concluídas e edição direta no formulário principal.
- **Exclusão segura:** Remoção de tarefas com confirmação antes de apagar.
- **Filtros e Contadores:** Filtragem por status (Todas, Pendentes, Concluídas) e contadores atualizados automaticamente.
- **Persistência Local:** Salvamento automático no navegador utilizando `localStorage`.
- **Feedback Visual:** Mensagens de confirmação exibidas na tela a cada ação realizada.
